# Cafeteria Sales Analysis using Python

##  Project Overview

Developed a **Cafeteria Sales Data Analysis project using Python** to clean, prepare, and explore transaction data. The project focuses on handling data quality issues, transforming data into suitable formats, analyzing relationships between numerical variables, and identifying item-level sales patterns.

##  Objective

* Clean and prepare cafeteria transaction data.
* Handle missing and invalid values.
* Convert data into appropriate formats.
* Identify duplicate records.
* Analyze relationships between numerical variables.
* Explore item-level transaction patterns.
* Generate a cleaned dataset for further analysis.

##  Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* CSV
* Google Colab / Python

##  Key Steps

* Loaded the cafeteria sales dataset using Pandas.
* Identified invalid values such as `UNKNOWN` and `ERROR`.
* Replaced invalid values with missing values.
* Handled missing values using mode-based imputation.
* Converted transaction dates, quantities, and prices into appropriate data types.
* Removed duplicate records.
* Removed remaining incomplete records.
* Performed numerical correlation analysis.
* Analyzed item frequency using a bar chart.
* Exported the cleaned dataset as a CSV file.
